# Chronicle OS v1.5

Retro Terminal Journal & AI — pure static web app.

## Live Demo

After enabling GitHub Pages:

**https://SenYu-Chi.github.io/chronicle_os/**

## Features

- Retro terminal UI
- Local-first data (localStorage)
- Gemini AI integration (bring your own API key)
- Thread / tag management
- Export data
- Mobile responsive

## Enable GitHub Pages

1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save

The site will be live in about 1 minute.

## Local Development

Just open `index.html` in a browser or use any static server:

```bash
npx serve .
```

## AI Setup

Click **[ai_config]** in the sidebar and paste your Gemini API Key.
